# AI 心理健康助手

一个基于 DeepSeek AI 的心理健康评估和建议系统，通过多维度问卷收集用户信息，并生成个性化的分析报告。

## 🌟 功能特性

### 完整的用户流程（新版）

1. **用户信息收集** - 收集年龄、性别、地址、职业等基本信息（带弹幕效果✨）
2. **评估模式选择**：
   - **详细版**：10个问题深入了解，第4个选项支持自定义输入
   - **快速版**：3个问题快速评估，第4个选项为"其他"
3. **核心问题输入** - 详细描述你最关心的问题（AI会重点针对此问题分析）
4. **咨询领域选择** - 四大咨询方向（气泡UI设计🫧）：
   - 📚 直面研途（学业压力、科研困惑）
   - 💝 情感需求（人际关系、情感困扰）
   - 🎨 兴趣爱好（兴趣培养、生活规划）
   - 🏃 健康管理（身心健康、生活习惯）
5. **问题问卷** - 根据选择的模式回答问题
6. **智能分析** - 基于所有信息调用 DeepSeek API（带进度条动画⏳）
7. **报告下载** - 纯文本格式，无Markdown标记

### 界面特色（全新升级）

- ✨ 现代化深色主题设计
- 📱 完全响应式，支持移动端
- 🎯 流畅的页面切换动画
- 💾 自动保存进度（使用 LocalStorage）
- 📊 圆形进度条显示（AI生成过程）
- 🫧 气泡UI设计（咨询方向选择）
- 🎬 动态弹幕效果（登录页面）
- ⬅️ 每页都有返回按钮（可重新选择）
- 📝 纯文本输出（自动去除Markdown格式）

## 🚀 快速开始

### 方式一：直接打开（最简单）

1. 双击 `index.html` 文件即可在浏览器中打开使用
2. API Key 已预配置，开箱即用

### 方式二：本地服务器（推荐）

使用本地服务器可以避免某些浏览器的跨域限制：

```bash
# 使用 Python 3
python -m http.server 8000

# 然后在浏览器访问
http://localhost:8000
```

或使用 Node.js：

```bash
# 安装 http-server
npm install -g http-server

# 运行服务器
http-server -p 8000

# 访问 http://localhost:8000
```

## 💡 使用说明

### 第一步：填写基本信息

在登录页面填写（背景有治愈系弹幕飘过✨）：
- 年龄
- 性别（男/女/其他）
- 地址
- 职业

**提示**：页面右上角有返回按钮，可随时回到上一步

### 第二步：选择评估模式

- **详细版（推荐）**：10个问题，约5-8分钟
  - 每个问题有4个选项
  - 第4个选项可以输入自定义答案
  - 更深入的分析和建议

- **快速版**：3个问题，约2-3分钟
  - 每个问题有4个选项
  - 第4个选项为"其他"
  - 快速获取基本建议

### 第三步：输入核心问题 ⭐ 新增

详细描述你最关心的问题：
- 最少10个字
- 越详细越好
- AI会重点针对这个核心问题进行分析
- 例如："我最近学习压力很大，经常失眠，不知道如何调整..."

### 第四步：选择咨询方向（气泡UI设计）

选择最符合你需求的领域：
- **直面研途**：适合有学业压力或科研困惑的用户
- **情感需求**：适合在人际关系或情感方面需要帮助的用户
- **兴趣爱好**：适合想要培养兴趣或规划生活的用户
- **健康管理**：适合关注身心健康的用户

**特色**：悬停时气泡会有弹跳和旋转效果🫧

### 第五步：回答问题

- 根据问题选择最符合你情况的选项
- 详细版支持输入自定义答案
- 进度条会实时显示完成进度

### 第六步：观看AI生成过程

系统会显示圆形进度条动画：
- 20% - 正在整理信息...
- 40% - 正在连接 AI...
- 60% - 正在生成分析...
- 80% - 正在处理结果...
- 100% - 完成！

### 第七步：查看AI分析报告

系统会自动整合：
1. 你的基本信息（年龄、性别、地址、职业）
2. 你的核心问题
3. 所有问题的回答
4. 调用 DeepSeek AI 生成专业建议

报告包含：
- 📊 基本信息汇总
- 💭 核心问题展示
- 💡 AI 个性化建议（纯文本，无Markdown标记）
- 针对核心问题的深入分析
- 当前状况评估
- 具体改善方案
- 鼓励和支持

### 第八步：下载报告

点击"下载报告"按钮可以保存为 `.txt` 文件，包含完整的分析内容。

## ⚙️ 配置说明

### 修改 API Key

如果需要使用自己的 API Key，在 `app.js` 第3行修改：

```javascript
const API_KEY = 'your_api_key_here';
```

### 自定义问题

在 `app.js` 的 `questions` 对象中可以自定义问题：

```javascript
const questions = {
    research: {
        detailed: [...],  // 详细版问题
        quick: [...]      // 快速版问题
    },
    // 其他分类...
};
```

## 🐛 故障排除

### 问题：AI 生成失败

**解决方案**：
1. 检查网络连接
2. 确认 API Key 是否正确
3. 查看浏览器控制台的错误信息

### 问题：页面显示异常

**解决方案**：
1. 清除浏览器缓存
2. 使用 Chrome/Edge/Firefox 等现代浏览器
3. 确保 JavaScript 已启用

### 问题：数据丢失

**解决方案**：
- 数据保存在 LocalStorage，清除浏览器数据会导致丢失
- 建议下载报告保存到本地
